@thalilmythos that shouldn't be happening, so I'd like to pin it down. Which car
is it? The mod reads the game's own FLAG_IS_ELECTRIC, and when it sees it the
gauge reads CHARGE instead of FUEL. So if yours says FUEL, that model isn't
flagged electric in its meta, which does happen with add-ons -- give me the model
name and I'll add it by hand. Worth checking [Fuel] AffectElectric = false in
your Fumes.ini too, in case an old ini carried it over as true.
